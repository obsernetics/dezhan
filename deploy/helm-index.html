dezhan Helm charts

On-prem, immutable, S3-compatible backup vault for Kubernetes.

Install

helm repo add dezhan https://obsernetics.github.io/dezhan
helm repo update
helm install dezhan dezhan/dezhan

Provision a vault with the operator at the same time:

helm install dezhan dezhan/dezhan \
  --set vault.create=true \
  --set vault.storage=100Gi

Then point any S3 client at http://<release>.<namespace>.svc:8080.

Source and docs: github.com/obsernetics/dezhan. Chart index: index.yaml.
